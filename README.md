# Hazze
The site for the brand new office fashion
## Project Description
**Hazze** is a fully functional website built on the **WordPress** platform. The project features a custom theme, responsive design, and an optimized structure for easy content management.

## Project Structure

### Main Directories
* **`/wp-admin`** — WordPress Administration Panel
* **`/wp-content`** — Themes, plugins, media files
* **`/wp-includes`** — WordPress Core
* **`/Source`** — Source files (SCSS, JavaScript)
* **`/fonts`** — Font files
* **`/img`** — Images
* **`/js`** — JavaScript files
* **`/css`** — CSS styles
* **`/dup-installer`** — Duplicator backup files

### HTML Pages
* **`index.html`** — Home page
* **`about-us.html`** — About Us page
* **`blog.html`** — Blog page
* **`blog-details.html`** — Blog post details
* **`contact.html`** — Contact page

### WordPress Files
* `index.php` — WordPress entry point
* `wp-config-sample.php` — Configuration example
* `wp-activate.php` — User activation
* `wp-login.php` — Login page
* `xmlrpc.php` — XML-RPC API
* `readme.html` — WordPress information
